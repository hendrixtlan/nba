# Platform references

Implementation choices should be verified against current Microsoft documentation before production deployment because the Foundry SDK and service surface evolve frequently.

Relevant official documentation:

- Microsoft Foundry SDKs and endpoints: https://learn.microsoft.com/en-us/azure/foundry/how-to/develop/sdk-overview
- Deploy your own code as a hosted Foundry agent: https://learn.microsoft.com/en-us/azure/foundry/agents/quickstarts/quickstart-deploy-own-code
- Connect to Microsoft OneLake: https://learn.microsoft.com/en-us/fabric/onelake/onelake-access-api
- OneLake API parity with Azure Storage: https://learn.microsoft.com/en-us/fabric/onelake/onelake-api-parity

- Fabric/OneLake medallion architecture: https://learn.microsoft.com/en-us/fabric/onelake/onelake-medallion-lakehouse-architecture
- Fabric Lakehouse and Delta tables: https://learn.microsoft.com/en-us/fabric/data-engineering/lakehouse-and-delta-tables
- Integrate OneLake with Azure Machine Learning: https://learn.microsoft.com/en-us/fabric/onelake/onelake-azure-machine-learning
- Azure ML datastores (including OneLake): https://learn.microsoft.com/en-us/azure/machine-learning/how-to-datastore
- Azure ML model registration: https://learn.microsoft.com/en-us/azure/machine-learning/how-to-manage-models
- Azure ML managed online endpoint authentication: https://learn.microsoft.com/en-us/azure/machine-learning/how-to-authenticate-online-endpoint
