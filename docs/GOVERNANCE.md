# AI / Decision Governance

## Required artifacts per use case

1. Business objective and measurable KPI.
2. AI-ready dataset assessment and owner.
3. Feature contract and lineage.
4. Model card and validation report.
5. Versioned commercial policy.
6. Agent tool allow-list and authorization model.
7. Golden evaluation set for agent behavior.
8. Human-approval policy for side-effecting actions.
9. Observability and cost budget.
10. Rollback and incident runbook.

## Guardrail philosophy

Guardrails should be implemented at multiple levels: identity, authorization, tool surface, input validation, policy engine, model constraints, response grounding and auditability. Prompt instructions alone are not considered a security or governance boundary.
